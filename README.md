# Md. Mostafizur Rahman Sourav — Portfolio

Personal portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — Main portfolio page (includes Web3Forms contact form and WhatsApp integration)
- `style.css` — Dark-mode responsive styling
- `script.js` — Mobile menu toggle, Web3Forms submission, and WhatsApp click-to-chat
- `.nojekyll` — Ensures GitHub Pages serves static files directly

## Deploy to GitHub Pages (No Git CLI required)
1. Go to [github.com](https://github.com) and create a new **Public** repository (e.g., `portfolio`).
2. Click **Add file → Upload files**, drag and drop `index.html`, `style.css`, `script.js`, and `.nojekyll`, then click **Commit changes**.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment → Source**, select **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
5. After 1–2 minutes, your live URL (`https://<your-username>.github.io/portfolio/`) will appear at the top of the Pages settings.
